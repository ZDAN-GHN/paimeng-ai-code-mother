# 管理后台

位置：`src/pages/admin/`

当前功能：应用管理、用户管理

## 权限

三层检查：

1. 路由守卫
2. 页面数据请求
3. 后端鉴权（最终防线）

## 列表页

保留现有：

- 分页
- 筛选
- 排序
- 刷新

## 操作

有副作用的操作（编辑、删除、精选）必须：

- 确认提示
- 加载锁定
- 成功反馈
- 失败反馈

删除操作不可用成功 UI 掩盖后端失败。

## 表单

- 使用 API 契约类型
- 提交前校验：数值、枚举、必填
- Ant Design Vue Form 组件

## 布局

- 桌面密集信息保持可扫描
- 窄屏按钮和关键字段不溢出
- 统一 Ant Design Vue 样式
