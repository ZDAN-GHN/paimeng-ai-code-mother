# 管理后台 UI

管理员功能位于前端 `src/pages/admin/`，当前包含应用和用户管理。权限校验要同时覆盖路由进入、页面数据请求和操作按钮；后端鉴权是最终边界。

列表页应保留现有分页、筛选、排序和刷新语义。编辑、删除、精选等有副作用的操作要有确认、加载锁定、成功反馈和失败反馈；删除不可用成功 UI 掩盖后端失败。表单提交使用 API 契约类型，数值、枚举和必填字段在提交前校验。

沿用 Ant Design Vue 的 Table、Form、Modal、Pagination 等组件，避免在管理页面复制一套请求或权限逻辑。桌面密集信息布局要保持可扫描，窄屏不得让按钮和关键字段溢出。
