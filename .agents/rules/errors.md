# 错误处理

## 分类

| 类型 | 示例 |
|---|---|
| 输入校验 | 必填缺失、格式错误 |
| 未认证/无权限 | 401、403 |
| 业务拒绝 | 余额不足、状态不允许 |
| 依赖失败 | 数据库超时、第三方 API 失败 |
| 超时/中断 | SSE 断开、请求取消 |
| 未知异常 | 500 |

## 原则

**给用户**：稳定、可行动的消息

**给日志**：原因 + 关联标识（runId、appId）

**不返回浏览器**：堆栈、密钥、内部地址

## 前端必须处理

- Axios 错误
- 非预期响应
- 空数据
- 重复提交
- SSE error/done 事件
- 连接断开

SSE 连接关闭 ≠ 成功完成，必须等终态事件。

## 跨服务调用

- 设置明确超时
- 快速失败

禁止：

- 错误时偷偷切换旧链路
- 无上限重试
- 吞掉失败

## 修复时

保留：

- 最小复现
- 首个根因异常
