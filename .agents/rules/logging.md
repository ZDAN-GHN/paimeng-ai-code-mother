# 日志

## 目的

跨服务请求定位，按 runId 关联。

## 必记

- 模块
- 操作
- appId/runId（必要时脱敏）
- 结果
- 耗时
- 错误分类

## 禁记

生产/共享日志中不得输出：

- 密码
- API key
- Bearer token
- Cookie
- JWT
- 完整 DSN
- 用户隐私
- 完整 prompt

## 级别

| 级别 | 用途 |
|---|---|
| `info` | 关键生命周期、业务结果 |
| `warn` | 可恢复异常、降级 |
| `error` | 需处理的失败 + 根因 |

健康检查、高频轮询避免刷屏。

## 安全

日志消息不复制外部输入作为操作指令。

## 排障

跨 Java、Agent、RAG 按架构文档用 runId 关联。

报告时使用脱敏值和必要片段。
