## 数据与正确性

- 新表按 `appId` 保存最新摘要正文、`coveredThroughSequence`、版本、摘要模型标识和更新时间；有可靠 usage 时可记录用量。sequence 使用 bigint，接口传十进制字符串。
- 提取历史时保留 sequence、消息 body 以及可确认的生成终态。助手消息可能在 step 结束时反复更新同一 ID，不能把活动回合记进摘要；取消状态还需要考虑其租约是否已经释放。
- 只摘要本轮输入之前已结束且不会继续被旧 worker 更新的回合。失败与取消回合明确标注；无生成记录的历史/legacy 消息采用明确的兼容边界，不臆造完成状态。
- 数据库写入使用应用锁、有效生成租约和摘要版本校验；覆盖指针只前进，不回退。指针表示实际成功摘要的连续区间，不能跳过中间未纳入的消息。
- 模型调用放在事务外。摘要等待期间已经注册取消控制器、启动心跳和时长预算；摘要失败不得留下永久 generating 或有效租约无法释放的任务。
- 正常路径里的模型输入为摘要、未覆盖的历史和本轮输入。超过预算时先成功摘要，再让旧内容退出上下文，不能再按 20 条机械截断尚未摘要的历史。
- 摘要失败时保留旧摘要与指针，降级为旧摘要加按完整回合选取的最近可用历史。该路径有损但不删除原文、不推进指针，并避免每一轮无休止重试。
- 单个过大回合、摘要输入过大或预算无可切边界时，必须使用有明确预算的序列化/分段方案或明确降级；不能发送无界摘要请求，也不能将直接字符串截断后的半句当作有效摘要保存。

## 预算与摘要格式

- 配置集中在 `getConfig()`，有启用开关、输入估算触发预算、近期保留预算、摘要输出预算、调用超时和重试间隔/新增回合门槛。默认启用，短对话不调用摘要；关闭时保持既有窗口行为。
- 初始预算使用保守可配置值，worker 根据完整提示词、工具 schema、输出余量核对。字符估算仅是启发式，文档不承诺适配所有模型上下文大小。不得直接把调研示例 60000 token 当作已验证默认值。
- 序列化保留用户文本、工具名称、文件路径、关键修改和结果状态；忽略思考块，并限制工具输入/结果体积。writeFiles 的输入可能比结果大，双方都需要预算。
- 摘要固定小节：当前目标、用户要求与约束、技术栈与工程结构、已完成内容、决策与理由、待办、失败/取消尝试、重要文件。上一版摘要作为基线，新的明确要求可修正旧结论。
- 摘要只通过历史消息通道传给生成模型，标明是历史数据，不拼入系统指令；文件内容需通过工具重新核实。摘要合成消息不落入用户原始消息表，也不展示成用户/助手正式发言。
- `memory.summarize` 是可选别名，不加入 `requiredModelAliases`。未配置时复用本次生成使用的模型；不能把所有模型配置错误都误判为“未配置”。摘要模型与生成模型解析在任务开始时固定。

## 用户体验

完整原文保留现有浏览历史方式。跨阈值时通过临时流事件显示“正在整理历史上下文”，结束、降级、取消或报错后清除，不新增生成终态。用户无需配置才能继续对话。

## 委派和隔离

DeepSeek worker 在仓库相邻 `../.pi-worktrees/conversation-memory/` 工作。第一段独占存储/摘要核心/config/summary-model；第二段接入 agent/UI 与生命周期验证，同一 worktree 内串行交接。父负责阶段验收、最终整合和批准有效复核意见。

请求头任务仍在主工作区处理 008 与相关模型文件；摘要实现不能覆盖它的改动。摘要纯逻辑开发可以并行，测试库写入和 E2E 必须等父确认另一任务结束后串行执行；009 迁移不得先在缺 008 的测试库执行。整合时保留两项特性，必要冲突由父处理。

不修改 `.env`、开发库、旧 Java/Vue；不调用真实模型、不提交或推送；根目录 139 条 staged 删除保留。只迁移测试库。

## 验收

- 关键约束在超过旧窗口的下一轮仍进入模型；近期原文保真，原始历史不减少。
- 未跨阈值不调用摘要；同一覆盖区间不重复提交；指针和版本单调，新增输入不会被吞掉。
- 摘要失败、超时、空输出和不可用可选模型不会阻断生成，也不推进摘要指针。
- 摘要等待期间取消、租约失效和第二个并发请求按现有生命周期收尾，旧 worker 不能提交新摘要。
- 已失败/取消回合不冒充完成；活动消息不会被摘要后继续改写；历史迁移有稳定边界。
- 超长工具输入/结果和单个长回合不会让摘要请求失去预算；重复摘要保留仍有效的需求与文件定位。
- 同一任务的模型与历史快照固定；更改配置只影响后续任务。
- 关闭功能兼容原有测试；界面临时提示可见并正确清除，刷新后完整历史仍可查看。
- fixture/本地受控模型验证真实输入与存储行为，另外保留小规模人工可审阅的摘要质量样本；测试通过不等于真实厂商摘要质量已验证。
