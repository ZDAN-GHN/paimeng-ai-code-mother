Route classification remains in Next: app type is selected before there is a generation conversation, it needs one structured enum, and already shares model management. Deterministic test routing can remain without constructing an SDK generation model. Existing product fixture generation is removed in U5.

Redis admission happens outside the Postgres write transaction: atomically reserve credit using a unique fixed-window id; refund that exact window if the later transaction rejects (including global concurrency, permission and duplicate checks). This preserves the tested rule that concurrent global admission rejects without consuming frequency credit, over-limit cannot write a generation or lease, and DB authentication/ownership remains in the transaction. Redis outage permits generation with a structured, sanitized warn, no silent fallback.

User's task4 premise of zero mysql2 source references differs from base: scripts/import-mysql-rows.ts still imports mysql2/promise and loads old rate_limit rows. Retire/archive that completed migration entrypoint consistently before removing mysql2, without touching archive/.
