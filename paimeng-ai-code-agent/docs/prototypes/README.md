# 界面原型

原型是界面层的推演：静态 HTML/CSS/JS，用来看界面、走流程、做评审。不进入生产构建，不连真实模型、数据库或部署。

放在哪一档、什么时候移动、移动后要改哪些引用，见 [docs/README.md](../README.md) 的「原型生命周期」。

## 每个原型的产出

| 文件 | 要求 |
| --- | --- |
| `index.html` | 双击就能开。没有外链、没有网络请求，字体只用系统中文字体栈。 |
| `README.md` | 怎么打开、能点什么、已知边界、演示数据声明。 |
| `preview-*.png` | 从本原型现场截的图。不外借、不合成、不用占位图代替。 |

## 边界

- 演示数据必须标注为演示；不虚构真实客户、用户量、价格或可访问的生产网址。
- 设计 token 的权威在生产代码。原型的 token 写在自己的 `DESIGN.md` 里（如 [darkroom](deprecated/darkroom/DESIGN.md)），采纳时提取进生产代码，不另设第二份 token 来源。
- 原型只解释界面，不承担契约。接口、表结构和运行约束写在 `docs/` 顶层文档里。
