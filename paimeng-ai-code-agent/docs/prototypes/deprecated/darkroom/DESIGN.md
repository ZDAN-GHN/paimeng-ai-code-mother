# Design system · 暗房

这份文件记录 `darkroom` 原型里已经成立的世界。它不是对旧 `v0-pi` 的修订，也不应该被当成生产 UI 的完整规范；生产落地时要按真实组件、可访问性和内容重新校准尺寸。

## 世界

**一间把描述显影成网站的小暗房。** 首页是接触印相 + 送洗单；工作台是灯桌 + 往来 + 打样记录；代码是负片；发布是出片单。

世界不是背景图，而是结构：胶片齿孔决定边距，接触印相决定首屏，灯桌决定预览的框、刻度与留白，工单决定输入区的层级，印章决定状态。没有“贴一张复古纹理”的中性模板。

页面只有这些颜色；**彩色属于作品**：六个样片、灯桌上的应用。界面 chrome 保持纸白 + 胶片黑 + 红 + 银。

## 字体

- **Noto Serif SC 900**：首屏标题、区块标题、样张书名、信件标题。字距 `-0.03em` 左右，标题不超过 76px。
- **Noto Sans SC 400/500/700**：正文、按钮、表单、说明。
- **Archivo 500/600**：`PAIMENG`、`PROOF`、`DISPATCH`、目录的英文小字。
- **Spline Sans Mono 400**：帧号、时间、卷号、条码下的编号、代码。
- 中文没有网络字体回退；四个 woff2 子集在 `fonts/`。完整授权见 `fonts/*-OFL.txt`。

## 组件

### 接触印相 / contact sheet

白色纸面 + 黑色胶片边 + 6 个 16:9 画幅。每格有帧号、边码、样品名和结构；红铅笔圈只圈当前那一张。它是首屏的主体，不是装饰背景。

### 送洗单 / lab order

白纸、黑色标题条、复写层、回形夹、红色“已收件”章。输入区是唯一的文本域；结构选项是四个小方票；主按钮是黑色块 + 红色箭头。它压在接触印相左下角，像一张真的工单。

### 章 / stamp

红色方形“派”是品牌章；状态章（已定影、制作中、已出片）用细边框 + 斜置；红色只出现在这些动作和状态上。章不是贴纸，遇到关键状态才盖。

### 灯桌 / light table

浅灰台面 + 24px 细网格 + 边缘刻度 + 竖向 “LIGHT TABLE / 041”。网格只因为下面是一张测量/对位桌；不要把它用到内容区。

### 样张 / print

白纸边 + 1px 黑框 + 裁切角标 + 红“样张”章 + 帧名/尺寸。正片是应用预览，负片是代码；两者同一张纸，不另起一套卡片。

### 打样记录 / proofs

黑底抽屉；白纸卡片；缩略图是主题的样张；当前版有红章；“取回这一版”是唯一的动作。版本只增不覆盖。

### 出片单 / dispatch

白纸、黑色标题条、复写层感、二维码、条码、红色“已出片”章。它是一次发布确认，不是普通成功 toast。

### 胶片边 / film edge

齿孔、帧号、`PAIMENG 400`。只出现在胶片/接触印相/页脚，不要用于普通面板的分隔。

## 规则

1. **先有物件，再有页面。** 每个区块问“它在暗房里是什么”，而不是“这里放什么卡片”。
2. **纸是纸，胶片是胶片。** 接触印相和工单有离桌阴影；胶片边是黑的；灯桌有网格；负片全黑。不要把这些材料混成一种“复古纹理”。
3. **彩色只属于作品。** UI 的彩色只有红章和红圈；样张自己的颜色不被品牌色覆盖。
4. **红色是动作/状态，不是氛围。** 一个视口里红色面积小；红色一多，就失去章的意义。
5. **没有圆角卡片。** 方纸、方框、方按钮；印章的轻微旋转是唯一的“手作”偏差。
6. **字距与字号是节奏。** 大标题紧，元数据松；帧号/边码可以很小，因为它们是印刷标记；可点击控件、状态、字段和正文 ≥11px，样片内部的微缩文字不算界面文字。
7. **一次动效。** 首屏红圈画出来；生成时样张从显影箱里抬出来；其余用状态切换，不撒 hover 特效。
8. **演示数据要诚实。** 名称、日期、地址都标演示；不借用外部角色图，不伪造客户和指标。

## 响应式

| 断点 | 变化 |
| --- | --- |
| ≥ 1120 | 接触印相 3×2；工单 380px；工作台 40/60 分栏 |
| 900–1119 | 首屏 3 列压缩；工单 365px；工作台工单栏 238px |
| ≤ 980 | 首页导航收进菜单；工作台工单栏变抽屉；对话/样张页签切换 |
| ≤ 820 | 首屏侧栏折到标题下；样品灯桌单列；胶片索引横滑 |
| ≤ 700 | 首屏变纵向：标题 → 工单 → 横向接触印相；工作台标题压缩、版本保留 |
| ≤ 420 | 首屏隐藏品牌小字；工单占满宽度；工作台隐藏状态章 |

在 1280×800 等短屏上，工单上移 34px，确保“开始制作”在第一屏内。

## 可访问性

- 主文字 ≥ 4.5:1；大标题 ≥ 3:1。红章、灰字在相纸上都过 AA。
- 所有图标是自绘 SVG；没有 emoji 或 Unicode 图标替代。
- 抽屉/出片单有焦点陷阱与 Esc；移动工单栏关闭时 `inert`。
- 生成/复制/暂停都有 `role=status` 的 toast；动效尊重 `prefers-reduced-motion`。
- 应用状态统一为“已出片”，生成过程单独用“已定影”；暂停/失败只影响本次过程，不覆盖上一张好片。
- 废片是暗房的失败物件，带“作废”章和“重新打样”的恢复入口。
- 胶片边码、帧号、打样流水号是装饰性微字，不承担操作；界面操作与正文 ≥11px。样片内部文字是作品里的微缩字。

## 资产

- 六个样片全部是 HTML/CSS 画的，没有照片、没有图库、没有 `public/paimeng.png` 的角色图。
- 字体自托管；没有 Google Fonts / CDN 请求。
- 出片单二维码是演示矩阵，条码是演示条码；不编码真实数据。
- 样张里的书名、作者、价格、地址都是虚构的演示内容。
- 负片是纸白 + 红 + 银的双色校样，不使用语法彩虹；彩色只留给样张。
