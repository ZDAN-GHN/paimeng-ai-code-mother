我们不追求
一次生成。

第一版只是曝光。它需要被打开、被点、被改，才慢慢定影。

所以每一版都留下，每次修改都能回头。你可以从任意一张重新开始，也可以把上一张取回来。

上线不是结束。它只是这卷片子，终于可以交到你手里。

工坊规则

  1. 先做出来

    第一版不用完美，它得先能被打开。

  2. 再改准确

    主色、字体、页面结构，都可以在对话里改。

  3. 每一版都留下

    打样记录可回看、可取回，不覆盖上一张。

  4. 最后定影

    上线前走一遍，发布后也能回来。
