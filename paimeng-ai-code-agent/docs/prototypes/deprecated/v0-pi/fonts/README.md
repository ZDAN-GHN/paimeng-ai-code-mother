# 字体来源与许可

原型为了离线可用，只自托管了三种拉丁字体。中文走系统字体，不打包。

| 文件 | 字体 | 用途 | 许可 |
| --- | --- | --- | --- |
| `Newsreader-latin.woff2`、`Newsreader-italic-latin.woff2` | [Newsreader](https://fonts.google.com/specimen/Newsreader) | 标题 / 正文衬线（替代 pi.dev 的 Plantin） | SIL OFL 1.1，见 `Newsreader-OFL.txt` |
| `JetBrainsMono-400-latin.woff2` | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | 代码、文件树 | SIL OFL 1.1，见 `JetBrainsMono-OFL.txt` |
| `DepartureMono-Regular.woff2` | [Departure Mono](https://github.com/rektdeckard/departure-mono) | 等宽小标签、figure caption | MIT，见 `DepartureMono-MIT.txt` |

- 两个来自 Google Fonts 的 woff2 是从 Google Fonts CSS 里取出的 **latin** 子集；中文由系统的 Noto Serif CJK SC / Songti SC / SimSun 渲染。
- pi.dev 使用的 Plantin 是商用字体，没有包含在本原型中。
- 文件名里的 `latin` 表示只含拉丁字符，不代表字体本身的授权范围。
