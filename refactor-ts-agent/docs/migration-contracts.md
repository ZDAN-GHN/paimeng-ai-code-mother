# 当前接口与页面迁移清单

原页面路径保留为 `/`、`/user/login`、`/user/register`、`/admin/userManage`、`/admin/appManage`、`/admin/chatManage`、`/app/chat/[id]` 和 `/app/edit/[id]`。

## 业务接口

用户接口保留注册、登录、退出、当前登录用户、公开用户详情、管理员用户详情、用户分页、管理员更新与删除，共 9 项。密码摘要不通过任何详情接口返回。

应用接口保留创建、更新、删除、详情、我的应用分页、精选应用分页、管理员分页、管理员详情、管理员更新、管理员删除、流式生成、发布与下载，共 13 项。精选条件保持优先级至少 99。所有数据库 ID 使用字符串。新增应用、用户及文本聊天历史使用与原 MyBatis Flex 1.11.1 相同 epoch 和位布局的雪花 ID，不再依赖数据库自增。已有记录保持原 ID。

历史接口保留应用历史分页与管理员历史分页，共 2 项。应用历史、完整工具消息和生成任务状态必须通过服务端归属校验。生成时不信任浏览器传入的其他应用上下文。

健康检查仍由 `/api/health` 提供。生成静态资源不复用旧项目的 `/api/static`，新预览由专门的隔离来源提供。这是安全边界的替换，旧静态接口不在新管理端暴露。

## 新增生成契约

`GET /api/app/messages` 返回权威完整 UIMessage 历史。`GET /api/app/generation` 返回生成、构建、完成、失败或取消状态。`POST /api/app/generation/cancel` 请求取消当前任务。

聊天使用 SDK POST 流式协议，不保留旧 GET EventSource 适配。重复请求 UUID 被拒绝再次执行，同一应用写操作使用数据库租约排除并发。服务进程中断后，租约到期，状态读取与后续提交会将旧任务明确标记为失败。

## 有意保留的运行差异

应用创建不再同步调用模型选择生成类型。没有显式类型时，依据明确的 Vue 或多文件关键词选择，否则采用 HTML。模型成本发生在用户提交生成消息时。登录与角色管理不依赖旧 Spring Redis 会话。

旧数据以经过校验的副本导入，保留业务主键。导入在停止平台写入的维护窗口进行，记录和本节点雪花发号下界一起提交；冲突整体回滚，不覆盖目标记录。当前 TS 节点明确采用数据中心 0、机器 0，并通过同一数据库持久化协调，不复现原 JVM 的 MAC 与 PID 推导。旧 Java 的最终快照需冻结后再导入，不能把未参与协调的发号器视为具有共同唯一性保证。模型完整工具消息存储于专用 TS 表，旧文本历史在首次生成事务中转换，不虚构旧工具调用。

页面样式使用集中式 `src/app/globals.css`，未采用计划中的 CSS Modules。八个原 URL 保留，桌面首页、桌面聊天和 390px 移动聊天经过截图及浏览器断言核对。未执行旧、新平台的逐像素对比。

生成源码和发布内容由独立预览来源公开读取。私有的是聊天历史及管理操作，不把来源隔离当作静态资源授权。旧六字符发布键可在复制后的发布目录中访问。仅复制未发布的旧源码不会建立新的 ready 任务，需要在新应用重新生成或构建后才进入当前预览、发布流程。

封面改为存储在 `runtime/covers/`，当前未接入 COS。生产构建使用标准 `next build` 和 `next start`，运行目录及 `.env` 排除在依赖追踪之外。没有执行公网部署或正式切换。

自动化模型使用显式 fixture，真实模型接口与对象存储仍缺少验收凭据。继承父模型的检查不能称为跨模型独立评审。
